# КОДИК — питомеци виртуалии девелопер

Тамагочии интерактивӣ барои даври 1/4. Чор персонаж: кодер, кот-кодер, баг ва AI-бот. Нишондиҳандаҳо бо гузашти вақт кам мешаванд, чеҳраи персонаж аз кайфият вобаста аст ва ҳар тугма садо ва аниматсия дорад.

## Чӣ кор мекунад

- **Энергия**, **кайфият**, **сифати код** ва **кофе** — ҳар сония оҳиста паст мешаванд.
- **Додани кофе** — энергия ва коферо зиёд мекунад. Аз ҳад зиёд кофе дастҳоро меларзонад.
- **Навиштани код** — лоиҳаро пеш мебарад ва энергияву коферо кам мекунад. Бе кофе сифат меафтад.
- **Ислоҳи багҳо** — кайфият ва сифати кодро баланд мекунад.
- **Истироҳат** — энергия ва кайфиятро барқарор мекунад. Шабона хоб қавитар аст.
- Агар питомецро фаромӯш кунӣ, ӯ меафтад. Тугмаи **Ребут** ӯро бармегардонад.
- Вақте лоиҳа ба 100% расид, деплой мешавад ва лоиҳаи нав оғоз мегардад.
- Ҳолат дар браузер нигоҳ дошта мешавад.

## Кушодан

Файлҳои `index.html`-ро дар браузер кушо, ё сервери оддӣ:

```bash
python -m http.server 5173
```

Баъд: [http://localhost:5173](http://localhost:5173)

Тугмаҳо: `1` кофе, `2` код, `3` баг, `4` хоб, `M` садо.

## Нашр

Лоиҳа статикӣ аст — бе қадами сохтан.

- **GitHub Pages:** репозиторийро бор кун, дар Settings → Pages шохаи `main` ва папкаи решаро интихоб кун.
- **Netlify:** папкаро ба [app.netlify.com/drop](https://app.netlify.com/drop) кашон.
- **Vercel:** `npx vercel` дар ҳамин папка.

Файли `.nojekyll` аллакай ҳаст, то GitHub Pages папкаҳои зеринро пинҳон накунад.
